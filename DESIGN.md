# Design notes

The six workflow skills were developed for a career-intake and multi-role resume-writing workflow. Four focused review skills cover technical positioning, accomplishments, section structure and parsing.

The user-supplied [ResumeSkills project](https://github.com/Paramchoudhary/ResumeSkills) informed which focused capabilities were useful. The four focused skills here are independently written, with different instructions and no copied templates or source text. They deliberately avoid forced numeric claims, blanket automated-rejection statistics and universal match thresholds.

Optional integrations considered: Resume / ATS Resume and CV Builder for editorial assistance, Resume Builder & ATS Checker for actual scores, document/PDF skills for export verification, and GitHub for authorized source inspection. Plugin prompts, code and proprietary materials are not redistributed.

No external course content, chapters, transcripts, examples or course dependencies are included. Candidate-specific preferences are honored as user configuration instead of baked into reusable instructions.

Publishing this collection does not authorize publication of any future user's resume or external application activity.

# Resume document delivery

Use settled draft text plus the evidence map and screening findings. If material claims are still disputed, keep the output provisional and say what is needed. Do not silently promote a draft to application-ready status.

Default final deliverables for each requested target: editable DOCX, selectable-text PDF, and plain TXT. Honor a different requested format or employer requirement. Use the available documents and PDF authoring skills for their respective formats, including render-and-inspect checks. If those skills/tools are unavailable, use an appropriate available method and disclose any unverified export or rendering limitation. Do not claim a DOCX/PDF was created merely because Markdown or HTML exists.

Keep contact information in the main body; ordinary headings and single-column flow. Use approximately 10.5-12 pt body text, restrained emphasis, readable spacing and margins; adjust through visual inspection rather than treating these ranges as universal rules. Avoid tables for the primary experience layout when ordinary paragraphs with tab stops suffice. Use clean page boundaries without orphan headings or broken bullets. Do not preserve the old resume layout at the expense of the user's request for a full rebuild.

Extract text from every final PDF/DOCX and verify key facts, characters, complete bullets and reading order against the source text. Render every page of the latest export and inspect for overlap, truncation, font issues and uneven density. Confirm PDF text is selectable rather than an image. Check hyperlinks when included. This is a local formatting check, not a certification of any proprietary ATS.

Keep reviewer notes, evidence IDs, unresolved questions, and source citations outside submitted resumes. Save the evidence bank and brief quality report separately for future tailoring. Use role directories and neutral filenames such as First_Last_Resume.pdf so application uploads do not expose draft iteration labels.

Deliver actual verified files with clickable links and a brief statement of roles, verification completed, and any material remaining limitation. Creating local files does not authorize publication, external scanner uploads, contacting references or job applications. Use a requested external checker through the screening stage only when authorized.

# Resume ATS Review


Treat parsing, employer matching/ranking, application questions and human review as distinct processes.

Use the current final document/text, not a stale draft:
1. Inspect name/contact, section order, employers, dated roles, complete bullets, degrees, technology terms and hyperlinks in extracted text.
2. Inspect PDF/Word layout separately. Look for missing text, columns that interleave, text boxes, inappropriate headers/footers, clipping and awkward page flow.
3. If an actual job description is supplied, map required/preferred qualifications to demonstrated evidence and resume placement. State supported, partial or missing evidence rather than an invented percentage.
4. Use an available external checker only with user authorization. Submit the complete current resume, not a favorable excerpt. Supply target company or job description only when given by the user and permitted by the tool.
5. Save the actual returned score, service, input version and analysis mode. Recheck affected results after substantive edits. Do not simulate a score when a plugin is unavailable.
6. Classify findings: real content/format issue, missing factual evidence, or parser false positive. Verify degree counts and grouped promotions locally. Do not change accurate verbs, invent jobs/dates or add unsupported metrics merely to satisfy a checker.

No universal score threshold or guarantee exists. A 97/100 resume-only tool score is not a 97% probability of an interview or ATS pass. Do not use blanket rejection statistics, hidden keywords, screening-model instructions or required keyword-density targets.

Return the strongest actual fixes first, checks performed, remaining limits and job-specific gaps. Read the sibling resume-screening-review for the broader credibility review.

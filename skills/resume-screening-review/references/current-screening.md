# Screening interpretation

ATS parsing, keyword/search retrieval, AI-assisted matching, application questions and hiring decisions are separate. Different employers configure different processes; a local document check cannot reproduce them.

For provider-specific explanations, inspect current official documentation at the time of use:
- Greenhouse parsing: https://support.greenhouse.io/hc/en-us/articles/200989175-Unsuccessful-resume-parse
- Greenhouse matching: https://support.greenhouse.io/hc/en-us/articles/41396009937307-Talent-Matching

Record what was actually verified and when. Do not describe these links as freshly checked unless opened. Avoid permanent assertions that every ATS uses AI, none uses AI, every resume is read by a human, or a particular percentage is automatically rejected.

Inspect actual exported text and page layout independently. Reconcile tool false positives with the source facts. An external scan is optional and requires user authorization to share their data.

# Metric integrity

Record a metric's value, unit, population, window, basis and attribution where known. Unknown fields remain unknown, not inferred.

- Eligible audience is not active users; daily conversations are not daily users.
- System throughput is product context unless the candidate's change created that capacity.
- Per-turn latency is not full-conversation latency; average is not p95.
- A cost reduction is not necessarily cost per request unless workload normalization is known.
- Minutes per batch cannot be rewritten as minutes per item.
- User-reported workflow savings are not measured company-wide productivity.
- A quality target is not an achieved quality result.
- No observed recurrence after a fix is not a permanent zero-error guarantee.
- Do not combine independent percentages or multiply estimated hours by assumed adoption into annual savings.
- Preserve observation method when it materially changes the claim: “merchants reported,” “production monitoring showed,” “before/after timings,” or “estimated.”

Prefer a concrete qualitative result over a manufactured number. When confidential amounts cannot be shared, ask whether a rounded value or nonnumeric outcome is acceptable.
